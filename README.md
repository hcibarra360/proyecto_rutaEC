# RutaEC - Sistema de Movilidad Urbana

Proyecto para la gestión y consulta de rutas de transporte público.

## Estructura del Repositorio
- **`/database`**: Scripts SQL y configuraciones de la base de datos.
- **`/rutaec-mobile`**: Frontend móvil desarrollado con Ionic, Angular y Capacitor.
- **`server.js`**: Backend de la API REST construida en Node.js y Express.

## Requisitos
- Node.js (v18+)
- Ionic CLI (`npm install -g @ionic/cli`)
